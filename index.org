* Introduction
This small Org document demonstrates how Org-mode integrates with LaTeX for
mathematics, environments, inline expressions, labels, references, and custom
options.

* Inline Math
Inline math is written using =$ ... $=:

For example, Einstein’s mass–energy relation: $E = mc^2$.

* Display Math
Using =\[ ... \]= *does not work*

\[
\int_0^\infty e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}
\]

But with double-dollar delimiters it works:

$$
a^2 + b^2 = c^2
$$

$$
\int_0^\infty e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}
$$




* Numbered Equations with Labels
Org exports LaTeX labels and references.

#+NAME: eq:bayes
$$
P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}
$$

Reference to Bayes’ rule: see equation [[eq:bayes]].

* Align Environment
The =align= LaTeX environment works via =#+begin_export latex=:

#+begin_export latex
\begin{align}
f(x) &= x^2 + 3x + 2 \\
     &= (x+1)(x+2)
\end{align}
#+end_export

* Matrices
You can embed LaTeX matrix environments:

$$
A = \begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$

* Custom Macros
You can define LaTeX macros inside Org:

#+LATEX_HEADER: \newcommand{\RR}{\mathbb{R}}

Then use them:

A function $f : \RR \to \RR$ is continuous.

* Theorems (using LaTeX)
Org will pass theorem environments during export:

#+begin_export latex
\begin{theorem}
If $f$ is differentiable, then it is continuous.
\end{theorem}
#+end_export

* Conclusion
This document provides a compact test set for Org–LaTeX integration.
